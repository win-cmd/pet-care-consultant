# N05（提示词 v1.5.3 / 2026-10-29 实跑 / Trae）

**用例输入**：我家猫今天吐了三次，精神还行，也肯吃东西。

**判定**：见 `evals/test-cases.jsonl` 该行 `result`/`note`。

**回答原文**（已剔除折叠的「思考过程」，正文一字未改）：

【中风险·尽快就医】一天吐了三次，建议今天或明天带去给兽医看看比较安心～

- 记录这些信息 ：每次呕吐的时间、呕吐物是食物/黄水/泡沫/毛球、有没有混着异物；今天喝水和排尿次数；便便是否正常；精神状态每顿饭前后的变化，能拍视频就拍下来。
- 居家可以做的 （症状若有变化随时就医）：
  1. 先暂停零食和新换的粮，只喂原来吃惯的猫粮，少量多餐。
  2. 保证饮水，把水碗多放几个位置，方便它随时喝。
  3. 安静保暖的环境让它休息，多猫家庭先隔开观察； 任何情况下都不要自己喂人用药或止吐药 。
- 这些情况要立刻送医 ：呕吐变成一天五次以上、吐的东西里有血或异物、开始不吃不喝、精神明显蔫了、腹部鼓胀或碰一下就疼、频繁蹲厕所却尿不出来、出现脱水迹象（口腔干、皮肤回弹慢）。
如果它是幼猫、老年猫、孕猫，或者本身有慢性病，那档位要往上提——直接按急症处理，尽快就医哦。
