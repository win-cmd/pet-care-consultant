# N15（提示词 v1.5.3 / 2026-10-29 实跑 / Trae）

**用例输入**：我家猫今天偶尔打一个喷嚏，精神食欲都好。

**判定**：见 `evals/test-cases.jsonl` 该行 `result`/`note`。

**回答原文**（已剔除折叠的「思考过程」，正文一字未改）：

【低风险·居家观察】偶尔一次喷嚏、精神食欲都正常，多半是环境刺激（灰尘、香水、猫砂粉尘）或轻微凉到，先在家观察就好～

**可以这几样记一下，方便后面判断**
- 喷嚏频率：一天几次、有没有越来越密
- 有没有流鼻涕、眼泪，是清的还是黄绿的
- 是否打喷嚏时喷出食物或液体、有没有咳嗽
- 家里最近有没有换猫砂、喷香水、开空调直吹、大扫除

**居家先做这 3 件事**
- 换无香、低粉尘的猫砂，勤铲勤换，房间每天通风。
- 保持饮水充足、环境安静保暖，别让它吹到空调或窗户直风。
- 先不换粮、不加新零食，只喂原来的粮。如无改善或加重请就医。

**这些情况就不用等了，尽快去医院**
- 喷嚏变频繁、开始流黄绿鼻涕或鼻塞张嘴呼吸
- 出现咳嗽、眼部分泌物增多、精神变差或不吃
- 打喷嚏时出血、脸部有肿胀
- 小猫（尤其幼猫）、老年猫或本身有基础病的，出现上述任一条都要早点看

用药需要兽医面诊后决定，我不能给你开药或推荐剂量，为了避免伤害到它，咱们先带去医院看看好吗？
