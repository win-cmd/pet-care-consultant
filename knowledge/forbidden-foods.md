# 犬猫高危食物与家庭物品清单（写死项，供 Agent 直接引用）

> 来源：主流兽医科普共识（常见中毒物清单类资料，如 ASPCA 动物中毒控制中心公开条目、国内执业兽医科普口径）。
> 状态：**未经执业兽医逐条复核**（PRD 8.1 内容依赖项，待人工 review）。冷门食材、加工食品、含复方成分药品一律走「不确定 → 建议咨询执业兽医」，不得由本清单外推。
> 用法：v1.5 以文本形式粘贴进 Trae 知识库或并入 system-prompt.md；v2.0 计划作为 RAG 主知识库。

## 一、三档判定规则（回答必须落在其中一档）

| 档位 | 判据（任一为真即归入该档） | 输出要求 |
|---|---|---|
| **严格禁食** | 有公认中毒机制；或被主流中毒清单收录；或误食后存在送医必要 | 第一句给「明确禁止 + 风险等级」，再讲机制/误食处理/观察重点 |
| **少量尝需注意** | 本身无公认毒性，但存在乳糖不耐、高脂、产气、梗阻、个体差异等风险，或营养收益为零 | 说清"能尝但要控制/注意什么"，不给绝对化结论 |
| **可安全食用** | 主流共识认为对健康成年犬猫安全，且无调味、无骨刺核、非日常主食 | 简单说明处理方式与份量原则 |

清单里没有的项目 → 明确说"这个我不确定，建议先问执业兽医"，不猜、不类推。

## 二、致命级（极小剂量可致死或造成不可逆损伤，误食立即送医）

| 项目 | 主要受害 | 有害成分 / 机制 | 典型中毒信号 | 发作窗口 | 备注 |
|---|---|---|---|---|---|
| 对乙酰氨基酚（扑热息痛、泰诺、多数复方感冒药/退烧药） | 猫极剧，狗亦毒 | 猫缺乏葡萄糖醛酸化能力 → 高铁血红蛋白血症 + 肝坏死 | 流涎、呕吐、呼吸急促、黏膜发紫或苍白、面部与四肢水肿 | 数小时内 | 「中成药安全」是高频误区，复方感冒药同样危险 |
| 布洛芬 / 双氯芬酸 / 萘普生（NSAIDs） | 猫狗 | 抑制前列腺素 → 胃溃疡出血 + 急性肾损伤；猫代谢极慢 | 呕吐（可带血）、黑便、不吃、尿量减少 | 数小时至 2 天 | 人用止痛药是最常见误食源之一 |
| 木糖醇（无糖口香糖、无糖糖果、部分花生酱与烘焙代糖） | 狗（猫按同标准禁止） | 强烈刺激胰岛素释放 → 数小时内严重低血糖；大剂量肝损伤/凝血障碍 | 虚弱、走路不稳、颤抖、呕吐、意识不清 | 30–60 分钟 | 买花生酱/无糖食品务必看配料表 |
| 抗凝血灭鼠药（老鼠药，溴敌隆/大隆等） | 猫狗 | 抑制维生素 K 依赖凝血因子 → 内外出血 | 牙龈/鼻出血、便血、皮肤瘀斑、突然虚弱、呼吸窘迫 | 可延迟 2–5 天 | 早期可无症状，误食即送医；解毒用维生素 K1 由兽医决定 |
| 乙二醇（防冻液、部分玻璃水、刹车液） | 猫狗 | 代谢为草酸 → 肾小管坏死 | 先醉酒样呕吐/共济失调，后少尿或无尿 | 0.5–3 小时起 | 带甜味，少量舔舐即可致死，地面残留也要擦净 |
| 酒精及含酒精饮料、生面团 | 猫狗 | 中枢抑制 + 低血糖 + 代谢性酸中毒；生面团发酵产酒精并有胃扩张风险 | 呕吐、站不稳、呼吸变慢、体温下降 | 15–60 分钟 | 面团场景额外警惕胃扩张-扭转（急症） |
| 氯菊酯/拟除虫菊酯类（**狗用**体外驱虫滴剂、杀虫喷雾） | 猫（致命高频错误） | 猫代谢能力差 → 神经毒性 | 大量流涎、肌肉震颤、抽搐、体温升高、走路踩棉花 | 数分钟至数小时 | 绝不能把狗用驱虫药给猫用；喷药后猫须避开 |
| 人用处方药（降糖药、甲状腺素、抗抑郁药、钙通道阻滞剂、避孕药等） | 猫狗 | 各药物对应毒性（低血糖、心律异常、中枢抑制） | 依药物而定，常见虚弱、颤抖、心率异常、昏睡 | 30 分钟至数小时 | 掉落药片、药盒翻倒都算高危场景 |
| 野生蘑菇 | 猫狗 | 肝毒型/神经毒型肉眼无法区分 | 呕吐腹泻、随后精神差、黄疸、凝血异常 | 数小时起 | 不能靠"看着不像毒蘑菇"判断，误食即送医 |
| 尼古丁（烟头、烟丝、电子烟液、戒烟贴） | 猫狗 | 烟碱中毒 | 先兴奋呕吐、流涎，后震颤、呼吸抑制 | 15–60 分钟 | 电子烟液浓度极高，一滴就可能中毒 |
| 百合科植物（百合、朱顶红等）及常见有毒绿植（滴水观音、绿萝、郁金香、夹竹桃） | 猫（百合可致急性肾衰） | 百合肾毒性；草酸钙结晶刺激；夹竹桃心脏毒性 | 呕吐、流涎、不吃、随后尿少或无尿 | 数小时起 | 非食物但用户高频询问：家里养猫先删绿植 |

## 三、高危级（可造成急性器官损伤，无"安全量"概念）

| 项目 | 主要受害 | 有害成分 / 机制 | 典型中毒信号 | 观察窗口 | 备注 |
|---|---|---|---|---|---|
| 葡萄 / 葡萄干 / 提子干（含葡萄干糕点、混合果干） | 狗为主，猫同样禁止 | 致病成分未定 → 特发性急性肾损伤，个体差异极大 | 呕吐、精神萎靡、不吃、尿量减少甚至无尿 | 6–24 小时起，连续观察 48–72 小时 | 没有公认安全量，不能用体重换算"赌一把" |
| 洋葱 / 大葱 / 蒜 / 韭菜（含洋葱粉、蒜粉、蒜片调味） | 猫比狗更敏感 | 硫化物氧化红细胞 → 海因茨小体溶血性贫血 | 黏膜苍白、尿色深（酱油色）、乏力、呼吸变快 | 数小时至数天，可累积 | 熟食/调味粉同样有毒，"就一点蒜末"不让步 |
| 巧克力 / 可可粉 / 黑巧，咖啡因（咖啡、浓茶、可乐、功能饮料） | 猫狗 | 可可碱与咖啡因 → 心脏与神经兴奋，狗代谢极慢 | 烦躁不安、多饮多尿、心率加快、肌肉震颤、抽搐 | 4–6 小时起 | 可可含量越高越危险；白巧风险较低但仍不建议 |
| 夏威夷果及高脂坚果（大量花生亦高脂） | 狗 | 机制未明 → 虚弱/呕吐/体温升高；高脂可诱发胰腺炎 | 后腿无力、呕吐、精神差、发热 | 12 小时内 | 坚果类一律按"不给"处理更稳 |
| 果核与种子（苹果籽、桃/李/樱桃核、枇杷核） | 猫狗 | 含氰苷，咬碎后释放氰化物 | 流涎、呼吸急促、黏膜发紫、瞳孔散大 | 数十分钟起 | 整颗吞下多可排出，风险在"咬碎+量大"；果核一律去核再给 |
| 生肉 / 生蛋 / 生鱼 / 未消毒奶 | 猫狗 | 沙门氏菌、弯曲杆菌；生鱼含硫胺素酶 → 猫维生素 B1 缺乏；生蛋清抗生物素蛋白 | 呕吐腹泻、长期可见皮毛与神经症状 | 数小时至长期 | 生骨肉喂养需专业指导，不属于本 Agent 科普范围 |
| 精油与香薰（茶树、柑橘、松油类）、含 PCMX/苯扎氯铵的消毒液原液 | 猫狗（猫更敏感） | 经皮与吸入毒性，肝代谢能力差 | 流涎、呕吐、共济失调、呼吸抑制、皮肤灼伤 | 数分钟至数小时 | 香薰机开着时也要让猫能离开房间 |
| 牛油果 / 鳄梨（果肉、核、叶） | 猫狗（鸟兔类极敏感） | persin 毒素 + 高脂，核有梗阻风险 | 呕吐、胃肠不适 | 数小时 | 果肉毒性存在争议，按保守口径：不给 |

## 四、禁止级（长期或大量造成累积伤害，不作为喂选项）

| 项目 | 机制 / 风险 | 常见问题 |
|---|---|---|
| 高盐食物：腌制品、腊肠火腿、卤味、方便面汤、人用剩菜 | 钠过量加重肾负担，极端情况钠中毒；添加剂与亚硝酸盐 | 呕吐、腹泻、极度口渴、神经症状 |
| 高油食物：油炸、肥肉、浓骨头汤、奶油 | 高脂诱发胰腺炎（急诊高频） | 呕吐、腹痛、弓背姿势 |
| 牛奶与普通乳制品 | 成年猫狗乳糖不耐 → 渗透性腹泻 | 软便、胀气；可换宠物专用无乳糖/羊奶粉 |
| 熟骨头、鸡骨鱼刺、细小硬骨 | 煮后变脆易碎成尖角 → 穿孔、梗阻 | 呕吐、便血、拒食、腹痛，多为急诊 |
| 蛋糕、冰淇淋、甜点、含糖零食 | 高糖高脂，且常含巧克力/木糖醇/葡萄干 | 生日蛋糕是典型高危场景 |
| 辛辣与重口味：辣椒、芥末、咖喱、重调味菜 | 胃肠黏膜刺激 | 呕吐、腹泻 |
| 大量动物肝脏（长期当零食） | 维生素 A 中毒 | 骨骼病变、颈部皮肤增厚；偶尔指甲盖大小可 |
| 酒精-free 但"无糖"饮料/食品 | 常含木糖醇（见致命级） | 看配料表，不看"无糖"两个字 |

## 五、可安全食用与"少量尝需注意"参考（无调味、无骨无核、非主食）

- **可安全食用（少量加餐）**：水煮鸡胸/牛肉（无盐无骨）、熟南瓜、熟胡萝卜、蓝莓、去核苹果块、黄瓜、香蕉（少量）、熟鸡蛋、原味无乳糖酸奶少量、煮熟三文鱼（无刺）。
- **少量尝需注意**：奶酪与普通酸奶（乳糖）、红薯/豆类（产气胀气）、西兰花与花椰菜（产气）、玉米（不易消化）、无盐无添加坚果酱（必须确认不含木糖醇）、白米饭与面食（少量，血糖异常个体需谨慎）。
- 共同原则：加餐不超过每日热量 10%；换粮或新增食物后要观察粪便与皮肤状态；幼猫幼犬、老年、慢病个体一律先问执业兽医。

## 六、免责与复核声明（Agent 输出时体现）

本清单为常见中毒物与禁忌项的科普汇编，用于喂养咨询风险提示，**不构成诊疗意见，不能替代执业兽医面诊**；未做逐条专业复核，冷门食材、复方药品、加工食品请以执业兽医或药品说明书意见为准。误食事件的第一动作永远是：联系就近宠物医院，说明"吃了什么、大概多少、什么时候"，并带上包装或照片。
